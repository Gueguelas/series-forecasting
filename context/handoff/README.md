# Handoffs — registro por sessão

Cada sessão de trabalho relevante gera **um arquivo** nesta pasta.

## Quando criar

- Ao pedir explicitamente: *"crie o handoff"*, *"registrar handoff"*, *"encerrar sessão"*
- Ao concluir trabalho substancial que o próximo integrante/agente precise continuar

## Nomenclatura

```
context/handoff/handoff_{resumo_da_sessao}.md
```

| Regra | Exemplo |
|-------|---------|
| Prefixo obrigatório `handoff_` | `handoff_eda_base_01.md` |
| Resumo em `snake_case`, minúsculas | `handoff_persistencia_artifacts.md` |
| Sem espaços, acentos ou caracteres especiais | `handoff_walk_forward_protocolo.md` |
| Curto e descritivo (3–6 palavras) | `handoff_context_engineering_grupo3.md` |
